Connect to GitHub

How do I get a token?
1. Go to github.com/settings/personal-access-tokens/new (you must be signed in to the GitHub account that owns/administers the sahabaclub.github.io repo).
2. Under Repository access, choose Only select repositories and pick sahabaclub.github.io.
3. Under Permissions → Repository permissions, set Contents to Read and write.
4. Click Generate token, then copy it and paste it above.
5. This token stays only in this browser (saved to local storage on this device) — it is never sent anywhere except directly to GitHub's API. Treat it like a password: don't share it, and revoke it from GitHub settings any time you want to cut off access.
