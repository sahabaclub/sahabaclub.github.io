Before you change anything

Nothing here is the original. Each service keeps its prompt in its own source file, and that is what runs until you activate something on this page — and what it falls back to the moment you press Use the code default, or if this database is ever unreachable. A bad edit is always recoverable.

Every change is tested before it can go live. Most of these services ask the model for a strict JSON shape, and a prompt that contradicts that shape does not fail loudly — it fails on every call afterwards, silently. So Test run makes one real call with your edit and the model you picked, and a version that has not passed cannot be activated. That is enforced in the database, not on this page.

The model list is live. It is fetched from OpenAI with the club's own key, so it is what this account can actually use today rather than what somebody typed into a file last year. Models are filtered by what the service calls: an image service is only ever offered image models.
