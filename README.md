# Sahaba Club website

The Sahaba Club homepage — a single page with an Individuals / Corporate toggle.

## Files

- `index.html` — all page content
- `styles.css` — all styling
- `script.js` — the Individuals/Corporate tab toggle

## Editing

Every visible word on the site lives in `index.html`. Open it, find the text you want to change, edit it, save, and re-upload to GitHub (or edit directly in GitHub's web editor). No build step, no install — it's plain HTML.

CTA buttons currently open an email draft to `info@sahabaclub.com`. Swap in a real form service (e.g. a Microsoft Form) later by replacing the `mailto:` links in `index.html`.

This site is published with GitHub Pages.
